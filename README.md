# 映像制作シート

映像制作の**構成表・カット割り表・撮影香盤表（コールシート）**を作って、A4のPDFに書き出すためのツールです。
HTMLファイル1枚だけで動きます。インストール不要、サーバー不要、オフラインでも使えます。

## 使い方

1. `index.html` をダウンロードする
2. ダブルクリックしてブラウザで開く
3. 枠の中をそのまま書き換える（入力は自動でブラウザに保存されます）

## 3枚のシート

上部のタブで切り替えます。画面に見えているものが、そのままPDFになります。

### 構成表
何を・どの順で・何秒見せるかを決めるシートです。

- 目標尺を入れると、**合計と差が自動計算**されます（オーバーは赤字）
- パートごとの尺の比率が**帯グラフ**で見えます
- 尺は `2:00` `120` `2分` のどれでも入力できます

### カット割り表（A4横）
構成表のパートごとに、カットを書き出します。

- Cut／画／動き／内容／セリフ・ナレーション／SE・音楽／尺／場所／小道具
- 画と動き（LS・MS・CU／Fix・PAN・手持ち など）は候補から選べます
- **構成の尺とカット合計の差**を各パートの見出しに表示します

### 撮影香盤表（コールシート）
当日、現場で配る1枚です。

- 撮影日（和暦で自動表示）、集合時間・場所、解散、演者、スタッフ、撮影場所、撮影シーン
- タイムスケジュール
- 準備物・買い物表は**チェックリスト**として入力できます
- 公開範囲のタグ（内部限定／外部関係先／制限なし）

## 構成表 → 香盤表への引き継ぎ

「香盤表へ引き継ぐ」から、構成表の内容を香盤表に流し込めます。取り込む前にプレビューで確認できます。

- パートを**撮影場所ごとにまとめ直して**撮影シーン欄へ
- **タイムスケジュールを自動生成**（撮影時間＝尺×倍率、場所ごとのセッティングと移動を挟む。倍率・分数・集合時間は変更可）
- カット割りの**小道具を準備物のチェックリストへ**（重複は除きます）
- 撮影日でしぼれるので、**日ごとの香盤表**が作れます

## PDF・印刷

- 「PDFに入れる」でページを選び、「PDFで保存」でファイルを直接書き出します（印刷ダイアログは不要）
- 用紙はA4。カット割り表だけ横向きで綴じられます
- 1ページに収まらない場合は、切れないよう自動で縮小します
- 「印刷」ではブラウザの印刷ダイアログが開きます

## データの保存

- 入力内容はブラウザに自動保存されます（localStorage）
- 「書き出す」でJSONとして保存、「読み込む」で復元できます。別の端末やスタッフに渡すときはこちら
- 「新規」で3枚まとめて白紙に戻します

## 動作環境

Chrome / Edge / Safari / Firefox の最近の版。ネット接続は不要です（フォントだけオンライン時にWebフォントを読みます）。

## 同梱しているもの

PDF書き出しに [html2pdf.js](https://github.com/eKoopmans/html2pdf.js) v0.14.0（MIT License）をファイル内に同梱しています。オフラインでもPDF保存が使えるようにするためです。
